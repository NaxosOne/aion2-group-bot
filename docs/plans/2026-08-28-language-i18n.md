# Per-server language (`/language`) + i18n — Implementation Plan

> **For Claude:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** Add a `/language` command that sets each Discord server's language (FR or EN), and route every user-visible string through a JSON-backed i18n layer so a server sees the bot exclusively in its chosen language.

**Architecture:** A dependency-free `bot/i18n.py` exposes pure helpers (`normalize_locale`, `pick_lang`, `t`) plus an async `resolve_lang(db, guild)`. Translations live in `bot/locales/{en,fr}.json` (flat dotted keys), guarded by a CI parity test. A per-guild override is stored in a new `guild_settings.language` column; when unset the language is auto-derived from `guild.preferred_locale`. The Discord `/` picker (command names/descriptions) is localized natively per user client locale via an `app_commands.Translator`; all runtime content (embeds, replies, DMs, button labels-at-send-time) follows the per-guild setting.

**Tech Stack:** Python 3.11, discord.py 2.4+, aiosqlite, pytest.

---

## Conventions for every task

- **TDD**: write the failing test, run it (expect fail), implement, run it (expect pass), commit.
- **No local Python?** Per project memory, Python may not run locally; verification is via CI. Still write tests first. Treat "run pytest" as "this must go green in CI". Do not mark a task done on unproven code.
- **Commits**: Conventional Commits, one atomic commit per task. No attribution footer (disabled globally).
- **Do NOT touch**: table/column names, `custom_id`s, log strings, code comments, or the technical `SystemExit` startup messages in `main.py`/`config.py`. Only user-visible runtime strings move to i18n.
- **Key naming**: flat dotted keys, namespaced by surface: `common.*`, `language.*`, `event.*`, `rsvp.*`, `signup.*`, `onboard.*`, `profile.*`, `poll.*`, `panel.*`, `group.*`, `legion.*`, `channels.*`, and `commands.*` (for `/` picker metadata). Placeholders use `str.format` style: `{name}`.
- **Test data**: existing tests pass plain dicts as event/signup rows; keep that. i18n helpers take a `lang: str` ("fr"/"en"), never a DB row.

```python
# bot/i18n.py
"""Server-language resolution and string catalog (FR/EN).

Pure helpers here take a language code ("fr"/"en"), never a DB row, so they
stay trivially testable. The catalog is loaded from bot/locales/*.json.
"""

SUPPORTED = ("en", "fr")
DEFAULT = "en"


def normalize_locale(locale: str | None) -> str:
    """A Discord locale ("fr", "fr-FR", "en-US"...) -> a supported language."""
    if locale:
        base = str(locale).lower().split("-", 1)[0]
        if base in SUPPORTED:
            return base
    return DEFAULT


def pick_lang(setting: str | None, guild_locale: str | None) -> str:
    """The language to use: explicit server override, else the guild's locale."""
    if setting in SUPPORTED:
        return setting
    return normalize_locale(guild_locale)
```

```python
import json
import logging
from pathlib import Path

log = logging.getLogger("kisk")

_LOCALES_DIR = Path(__file__).parent / "locales"


def _load() -> dict[str, dict[str, str]]:
    catalogs: dict[str, dict[str, str]] = {}
    for lang in SUPPORTED:
        path = _LOCALES_DIR / f"{lang}.json"
        catalogs[lang] = json.loads(path.read_text(encoding="utf-8"))
    return catalogs


_CATALOGS = _load()


def t(key: str, lang: str, /, **params: object) -> str:
    """Translated, formatted string. Never raises inside a handler.

    Missing key/lang -> fall back to the default language, then the raw key.
    """
    lang = lang if lang in SUPPORTED else DEFAULT
    template = _CATALOGS.get(lang, {}).get(key)
    if template is None:
        template = _CATALOGS.get(DEFAULT, {}).get(key)
    if template is None:
        log.warning("i18n: missing key %r", key)
        return key
    try:
        return template.format(**params) if params else template
    except (KeyError, IndexError):
        log.warning("i18n: bad placeholders for key %r", key)
        return template
```

```python
async def resolve_lang(db, guild) -> str:
    """Server language: explicit override, else the guild's Discord locale."""
```

```python
# bot/cogs/settings.py
"""The /language command: choose the server's language (FR / EN / Auto)."""

import discord
from discord import app_commands
from discord.ext import commands

from .. import i18n

LANG_LABEL = {"fr": "Français", "en": "English"}


def choice_to_lang(value: str) -> str | None:
    """The stored column value for a picker choice ('auto' -> None)."""
    return None if value == "auto" else value


@app_commands.guild_only()
class Settings(commands.Cog):
    def __init__(self, bot: commands.Bot):
        self.bot = bot

    @app_commands.command(
        name="language",
        description="Set the language Kisk uses on this server",
    )
    @app_commands.describe(choice="The language for this server")
    @app_commands.choices(choice=[
        app_commands.Choice(name="Français", value="fr"),
        app_commands.Choice(name="English", value="en"),
        app_commands.Choice(name="Auto (Discord server language)", value="auto"),
    ])
    @app_commands.default_permissions(manage_guild=True)
    async def language(
        self, interaction: discord.Interaction, choice: app_commands.Choice[str]
    ):
        lang_value = choice_to_lang(choice.value)
        await self.bot.db.set_language(interaction.guild_id, lang_value)
        # Confirm in the language that now applies.
        effective = await i18n.resolve_lang(self.bot.db, interaction.guild)
        if lang_value is None:
            text = i18n.t("language.auto_confirm", effective)
        else:
            text = i18n.t(
                "language.set_confirm", effective, language=LANG_LABEL[lang_value]
            )
        await interaction.response.send_message(text, ephemeral=True)


async def setup(bot: commands.Bot):
    await bot.add_cog(Settings(bot))
```

In `bot/main.py` `setup_hook`, add alongside the other `load_extension` calls:

```python
from . import i18n


class KiskTranslator(Translator):
    async def translate(self, string: locale_str, locale, context) -> str | None:
        key = string.extras.get("key")
```

## Notes / risks

- **Command names stay English identifiers** (Discord charset limits per locale); only descriptions/param-descriptions are localized in the `/` picker.
- **Persistent view labels**: safe to translate at send time because Discord stores the rendered label; the startup `add_view(...)` registration only routes clicks by `custom_id`. Never change a `custom_id`.
- **Global command sync**: one shared command set across all guilds — this is exactly why runtime content (not command metadata) carries the per-guild language.
